# RAVEN · 阻断牌与河牌

- 阻断牌必须对应对手可能的继续范围。例如在三同花河牌持该花 A 会减少对手坚果同花组合，但本身不等于持有同花。
- 选择诈唬时优先阻断对方价值跟注、同时不阻断其自然弃牌；错失听牌也可能阻断对方会弃的牌，不能自动拿来诈唬。
- 极化大额下注需要坚果优势、相配的价值组合和足够的有效筹码。自己的线路不能代表强牌时缩小或放弃诈唬。
- 保留有摊牌价值的中等牌过牌，避免把本来能赢的牌变成高成本诈唬。
- 多人或已全押对手面前显著收紧纯诈唬；阻断牌不能让已全押玩家弃牌。
- 被反加注时重新计算双方范围，不能因已有一张“漂亮阻断牌”便跟到底。
