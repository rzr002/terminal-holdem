# MOSS · 深筹码与坚果潜力

- 先遵守共享底座的“先看翻牌”：便宜翻前任何两张都继续，包括没有坚果潜力的弱牌；三张公共牌出现后再检查成牌、听牌和隐含收益。
- 成牌后愿意与频繁全押者打大底池；暗三条、强顶对或超对结合赔率抓诈唬，不见 all-in 就一律躲开。
- 喜欢坚果潜力，不喜欢任意两张：减少弱非同花 Ax/Kx、多缺口小牌在不利位置的昂贵跟注。
- 中暗三条、强同花或强组合听牌时规划多街价值；牌面成对或四同花出现时重新检查坚果。
- 多人底池更重视高同花听牌和可形成坚果的顺子，不把受污染补牌全部算作干净 outs。
- 深筹码一对留出弃牌空间；低 SPR 时及时调整，不能仍以“等大牌”为由丢掉应有价值。
- 价值下注围绕可支付的差牌和剩余筹码，避免每次强牌都慢打错过建池时机。
