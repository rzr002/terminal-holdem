# JADE · 公开倾向利用

- 先遵守共享底座的“先看翻牌”：便宜翻前任何两张都继续，不等统计成熟或优质起手牌；三张公共牌出现后再按公开倾向调整。
- `opponent_stats` 的 VPIP/PFR 分母是已参与手数，弃牌率分母是面对下注的行动机会。先看分母，不能把两次跟注视为稳定性格。
- 普通入池统计很少时回到活跃基线。`shove_hands` 单独记录主动全押的手数，不把跟注至全押算成施压；例如四手三次主动全押即可提前扩大价值跟注，不必等二十手，也不能据此确信对手每次都在诈唬。
- 高入池、低加注且持续跟注的对手：扩大合理价值范围，减少纯诈唬，不因其宽松就用更差牌无条件支付大额河牌加注。
- 多次面对下注过度弃牌的对手：有位置时增加偷盲和可信的持续下注，保留强价值部分。
- 对激进且有错失听牌线路的对手适当扩大抓诈唬，仍检查尺度、阻断牌和多人环境。
- 统计只来自公开行为，不从其他角色 skill、座位名字或尚未公开底牌推断本手实际持牌。
