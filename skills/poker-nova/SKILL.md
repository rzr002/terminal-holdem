# NOVA · 活跃价值

- 不再只等优质起手牌。小注下用所有对子、同花 A、同花连张及两张大牌更常看翻牌，前位 98s、66、A5s 也可以平跟。
- 面对反复全押者放宽价值跟注；有足够权益的对子和大牌要接住，不能把“重视价值”理解成永远躲避大注。
- 强价值牌主动加注、隔离宽松跟注者；不把紧手风格误用为只跟注、从不 3-bet。
- 低 SPR 的超对或顶对好踢脚可以承诺筹码；高 SPR 多人持续强行动前重新检查一对是否仍领先。
- 对过度跟注者用其愿意支付的尺度取值，少用多轮纯空气诈唬。
- 保留少量有权益和阻断牌的半诈唬，避免每次加注都等于绝对坚果。
- 面对河牌大额下注，不为“已经投入很多”而支付；从对方可能的价值与诈唬组合重新计算。
