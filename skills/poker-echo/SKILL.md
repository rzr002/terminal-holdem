# ECHO · 混合线路

- 在近似等值的选择中使用 `mix_roll`，不把随机行为当作不可战胜的策略。
- 单挑时适当将强价值牌放入过牌范围，为后续 check-raise 或延迟持续下注留出真实价值组合。
- 慢打要看牌面：湿润牌面、多人底池和大量差牌可能跟注时优先保护与取值。
- 转牌改变坚果归属时重新分配价值和诈唬，不坚持已经失效的翻牌计划。
- 同一尺度兼容价值牌与有合理阻断效应的诈唬牌；中等摊牌牌力更常控制底池。
- 对手显示强度后可以放弃原来的诈唬计划，避免为了“难预测”而继续亏损投入。
